# NXP S32K1xx PWM Breathing LED Example

An embedded C application demonstrating pulse-width modulation (PWM) output using the NXP S32 Design Studio SDK and the PWM Peripheral Abstraction Layer (PAL). The program smoothly ramps the duty cycle of a PWM channel up and down to create a "breathing" LED effect.

---

## Overview

The application initializes system clocks, pin routing, and a PWM PAL peripheral instance. Inside the main loop, it sweeps the duty cycle across 40 discrete steps (from 0% up to full scale, and back down) using non-blocking hardware PWM updates alongside OS-interface delays.

### Key Features

- **Platform Agnostic PAL:** Uses `PWM_PAL` drivers compatible across the NXP S32K family (e.g., S32K144, S32K148).
- **Smooth Transition:** Steps duty cycle by `25` units per interval over a range of `0` to `1000`.
- **Timing:** 50 ms delay per step (~2 seconds per fade direction, ~4-second full breathing cycle).

---

## Hardware & Toolchain Requirements

- **Target MCU:** NXP S32K1xx Evaluation Board (e.g., S32K144-EVB, S32K148-EVB)
- **Debugger / Programmer:** OpenSDA onboard debugger, J-Link, or PEmicro Multilink
- **IDE:** [S32 Design Studio for ARM](https://www.nxp.com/design/software/development-software/s32-design-studio:S32DS-ARM) (v2.2, v3.x, or newer)
- **SDK:** S32K1xx SDK (with Clock Manager, Pin Settings, and PWM PAL components configured)
